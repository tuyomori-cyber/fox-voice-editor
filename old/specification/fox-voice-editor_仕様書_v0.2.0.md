# fox-voice-editor 仕様書 v0.2.0（実用テスト版）

作成日：2026-10-25  
基準：v0.1.7  
状態：v0.2.1により更新済みの基準仕様。v0.1.7以前の経緯・計測原則は維持する。定型削除に関してはv0.2.1を優先する。

## 1. 目的と原則

fox-voice-editorは、Linux側で音声を日本語テキストへ変換し、結果を独立した文章ブロックとして組み立てるFirefox拡張である。短い発話、定型句、記号、手入力を同じ文書ブロックとして扱い、タッチ中心で文章を作る。

- Firefoxは録音・音声データの中継を行わない。Native MessagingでLinux側へ固定の制御要求を送り、状態と認識結果テキストだけを受け取る。
- 音声認識結果を勝手に校正・要約・意味変更しない。
- 認識・保存・Focodex連携を契機に、任意のOSコマンド、Codex、AI処理を実行しない。
- 音声ブロック、手入力、履歴、定型、記号から追加したブロックは、文書上では同じ編集対象である。
- 主対象はSurface Pro 4 / Fedora / Cage / Firefoxのタッチ操作、開発・検証環境はXubuntu / Firefoxとする。

## 2. 画面とスクロール

編集画面は左の文書ペインと右のライブラリペインからなる。

- デスクトップ幅では左右ペインを独立してスクロールする。左ペインはブロック、手入力、プレビュー、連携設定までをスクロール対象とする。
- 右ペインは「履歴」「定型」「記号」のタブ列を固定し、選択中タブの内容だけをスクロールする。
- 狭い幅では1列に積み、通常のページスクロールを使う。
- 通常モードではブロック領域・プレビュー周辺のドラッグはスクロールに使える。並べ替え・追加モード中の文書ブロックと外部カードだけはドラッグ操作を優先する。
- 認識エンジン選択の右側に「内部状態」を置く。接続、マイク補正、モデル準備、計測値はこのポップアップだけに表示し、通常画面には常時出さない。エラー表示は通常画面に残す。

## 3. 録音と認識

### 3.1 基本動作

- 録音開始／停止は単一トグルボタンで行う。キャンセル操作を別途提供する。
- Linux側が録音、必要な音声変換、認識を行う。成功した認識結果は末尾の新規ブロックとして追加し、履歴にも登録する。
- 失敗、キャンセル、空文字列では文書・履歴を変更しない。
- 録音上限は暫定30秒とする。
- 接続時に`prepare_microphone`を実行し、成功または`skipped`まで録音を無効化する。録音ごとの自動再確認は行わず、「マイクを再確認」で明示的に再実行する。

### 3.2 エンジン

- 選択肢は`Whisper（base）`と`ReazonSpeech K2（INT8）`。選択は`browser.storage.local`へ保存し、未設定時はWhisperを使う。
- Whisperは`ggml-base.bin`と`-l ja`を用い、録音ごとにCLIを起動する。
- ReazonSpeechは編集タブとNative Host接続の存続中に専用Workerへ一度だけ初期化し、連続録音で再利用する。録音を開始せずに`prepare_engine`で準備する。
- マイク準備と選択エンジンの準備が両方完了するまで録音不可とする。録音・認識中はエンジン切替を禁止する。
- 結果は`recordingId`、エンジン、世代番号で検証し、対応不能な結果を文書へ追加しない。

### 3.3 計測

- WhisperはA（停止〜変換完了）、B（CLI起動〜モデル準備完了）、C（モデル準備完了〜認識終了）、停止操作〜結果表示の総時間を表示する。旧CLIで計測点がなければ`計測不可`とする。
- ReazonSpeechは準備時間を録音前に表示する。録音ごとはA、推論時間、停止操作〜結果表示の総時間を表示し、モデル読み込みは「セッション開始時に実施」と区別する。
- 総時間の暫定目標は3秒以内、5秒以内を実用範囲とする。初回準備時間とは混同しない。

## 4. 文書ブロック編集

### 4.1 通常モード

- 文書ブロックは文字列を角丸カードで横並び・折り返し表示する。見出しは置かない。
- タップで複数選択でき、再タップでそのブロックの選択を外す。
- 選択ブロック群の直下、手入力欄の前に共有操作メニューを表示する。「削除」は選択中の全ブロックを削除し、複数選択時は「選択解除（すべて）」を表示する。
- 履歴と文書ブロックを各1件だけ選択した場合に限り、「前へ挿入」「後ろへ挿入」を表示する。挿入した履歴語句は独立した文書ブロックになる。
- 録音中・認識中・ライブラリ読込中は編集操作を無効化する。

### 4.2 並べ替え・追加モード

- 「並べ替え・追加」で明示的に切り替える。有効中のボタンは黒地・白文字で表示し、ラベルは「並べ替え・追加を完了」とする。
- 文書ブロックはドラッグで並べ替える。指を離した順序を保存する。
- 履歴、定型、記号のカードを文書ブロック枠へドラッグすると、ドロップ位置に新規ブロックを追加する。
- このモード中は文書・履歴・定型・記号のタップ選択を無効化し、誤タップを防ぐ。
- 履歴からのドラッグは**複製**である。履歴の削除、使用回数、並び順、ピン留め状態を変更しない。履歴の削除は履歴タブの明示操作だけで行う。

### 4.3 手入力とFX-OSK

- ブロック枠の下に手入力欄、「追加」「定型へ追加」を置く。
- 手入力欄へフォーカスすると、欄を左ペインの中央へ寄せてから、設定済みFX-OSKを埋め込み表示する。キー入力は手入力欄へ反映する。
- OSKを閉じた時、または手入力欄からOSK以外の操作へフォーカスが移った時は、埋め込みiframeを破棄して下側の操作を覆わないようにする。次回フォーカス時は新規生成する。
- 「追加」は文字列を末尾の独立ブロックとして追加し、履歴にも登録する。「定型へ追加」は文書を変更せず定型と履歴へ登録する。空文字列は追加しない。
- FX-OSKの拡張IDは拡張連携設定で保存する。外部拡張からはキーボードフレームURLと許可済み編集キーだけを受け付ける。

## 5. 履歴・定型・記号

### 5.1 履歴

- 認識成功、手入力追加、定型追加で履歴へ自動登録する。同じ文字列は重複保存せず、明示的な履歴再利用時だけ使用日時・回数を更新する。
- ピン留めを先に、通常履歴を新しい順に横並び・折り返し表示する。ピン留め群の後で改行する。通常履歴は30件ずつ表示する。
- 通常モードでは複数選択し、共有操作メニューから一括ピン留め／解除、履歴から削除、選択解除を行える。実行後は選択を解除する。
- 暫定上限は500件。超過時は古い通常履歴から削除し、ピン留めは自動削除しない。履歴の削除は文書ブロックへ影響しない。

### 5.2 定型

- 定型は履歴とは別の保存集合で、履歴と同じカード形式・右ペインの「定型」タブで表示する。
- 手入力欄の「定型へ追加」で登録する。定型は並べ替え・追加モードで文書へドラッグ複製できる。
- 定型からの文書追加は、定型を削除せず、履歴を再利用として更新する。

### 5.3 記号

- 記号タブには、日本語JISキーボードで使う句読点、括弧、全角・半角の演算子・記号、通貨記号を固定表示する。
- 全角・半角は別文字として扱う。固定記号そのものは履歴・定型へ保存しない。
- 記号は並べ替え・追加モードでのみ文書へドラッグ追加でき、追加後は`origin: "symbol"`の通常ブロックとなる。

## 6. プレビュー、コピー、Focodex連携

- プレビューは文書ブロックを表示順に区切りなしで連結する。空白・改行を自動挿入しない。
- 「コピー」はプレビューと完全に同じ文字列をクリップボードへ書き込む。
- 「Focodexへ貼り付け」は同じ文字列をFocodexのFIFO受信バッファへ送る。受信だけでは入力欄への反映、Codex実行、AI処理をしない。
- 応答不明時は「同じ文章を再送」で同一要求ID・本文を明示再送する。自動再送と状態照会はしない。
- 送信先Focodex拡張IDとFX-OSK拡張IDは「拡張連携設定」にまとめて保存する。Focodex連携の詳細契約は[specification-focodex連携.md](specification-focodex連携.md)を正本とする。

## 7. 保存とライフサイクル

### 7.1 保存

- 文書ブロックと画面設定は`browser.storage.local`へ保存する。
- 履歴・定型の正本はNative Hostが`~/.local/share/fox-voice-editor/library-v1.json`へ原子的に保存する。権限は所有者だけが読める形を使う。
- 拡張側の履歴・定型は画面用キャッシュとする。正本がない初回は既存キャッシュを移行する。
- Temporary Add-onを削除・再読み込みしても、同一Linuxユーザー・同一Hostなら履歴・定型は復元する。

### 7.2 接続と復帰

- `connectNative("fox_voice_editor")`の持続接続を使う。録音音声や任意コマンドは送らない。
- Split View移行などで発火し得る`pagehide`を理由に接続を明示切断しない。
- bfcacheからの`pageshow`で接続が失われている場合だけ再接続する。二重接続と、古い接続の切断通知による新接続状態の上書きを防ぐ。
- 接続断、Host異常終了、Firefox終了時には録音プロセス、認識Worker、一時ファイルを後片付けする。ページ破棄後の録音継続を許さない。

## 8. データと固定通信

文書の保存スキーマは`schemaVersion: 1`を維持する。

```json
{
  "schemaVersion": 1,
  "document": {
    "blocks": [
      {"id": "b1", "text": "Firefox", "origin": "voice"},
      {"id": "b2", "text": "の", "origin": "history"},
      {"id": "b3", "text": "、", "origin": "symbol"}
    ]
  },
  "history": [
    {"id": "h1", "text": "既存機能は維持", "pinned": true, "lastUsedAt": null, "useCount": 0}
  ],
  "templates": [
    {"id": "t1", "text": "確認してください", "pinned": false, "lastUsedAt": null, "useCount": 0}
  ]
}
```

- ブロックIDは一意であり、外部カードから追加する時も新規IDを発行する。`origin`は追跡用で、編集上の権限差は持たない。
- Native Hostへの固定要求は`prepare_microphone`、`prepare_engine`、`start_recording`、`stop_recording`、`cancel_recording`、`get_status`、`load_library`、`save_library`とする。
- `prepare_engine`のエンジン値は`whisper`または`reazonspeech_k2`のみ許可する。自由なコマンド、パス、実行引数は受け付けない。

## 9. セキュリティとプライバシー

- マイク利用は明示的な録音操作時だけであり、モデル準備・マイク補正は録音を開始しない。
- 録音・認識はローカルで完結し、クラウドへ音声を送らない。原音声は恒久保存しない。
- Surface固有のマイク補正は、Host側の`~/.config/fox-voice-editor/microphone.json`で`{"boost_fix": true}`を明示した端末だけで行う。対象は固定の`PCH` / `Internal Mic Boost` / `0`であり、拡張から変更できない。
- FocodexとFX-OSKの拡張間通信は設定済み拡張ID、既知のメッセージ型、既知のフレーム起点だけを受け付ける。

## 10. 実用テストの受け入れ条件

1. WhisperとReazonSpeechで録音開始・停止・キャンセル・結果追加・履歴登録を確認する。
2. ReazonSpeechで初期化が1セッション1回であること、連続3回以上の結果対応、停止〜表示時間、終了時Worker回収を確認する。
3. 通常モードで複数選択、削除、選択解除、履歴からの前後挿入を確認する。
4. 並べ替え・追加モードで文書並べ替え、履歴・定型・記号のドラッグ追加を確認し、履歴ドラッグ後も元の履歴が残ることを確認する。
5. 手入力、追加、定型追加、FX-OSKの初回表示・閉鎖・再表示を確認する。OSK利用後もコピー、Focodex送信、再送、拡張連携設定、削除操作が使えることを確認する。
6. Split Viewで左右の独立スクロール、右タブ固定、ブロック直下の操作メニュー、接続維持を確認する。
7. Temporary Add-on再読み込み後に文書キャッシュ、履歴・定型の正本復元、エラー時の通知を確認する。
8. Focodex実通信でFIFO受信、明示反映、同一ID再送、拒否時の副作用なしを確認する。
9. Surfaceでマイク補正、数字・技術用語の認識品質、CPU・メモリ、画面終了時の後片付けを確認する。

## 11. v0.1.7からv0.2.0への変更

- 手入力によるブロック追加と定型登録、定型タブ、記号タブを正式機能化した。
- 履歴・定型の正本をNative Host固定パスへ移し、Temporary Add-on再読み込み後の復元を可能にした。
- 履歴・定型・記号を並べ替え・追加モードから文書へドラッグ複製できるようにした。履歴ドラッグは履歴を変更しない。
- FX-OSKを拡張IDで連携し、手入力フォーカスでの表示、画面幅に応じたキー寸法、閉鎖後のiframe破棄と再表示を追加した。
- Focodex受信バッファ連携、同一ID・本文による明示再送、連携設定の統合を追加した。
- 2ペイン独立スクロール、右タブ固定、選択操作メニューのブロック直下表示、並べ替え・追加モードの視覚的強調を追加した。
- Split Viewでの`pagehide`によるNative Host誤切断を廃止し、復帰時だけ必要なら再接続するようにした。

## 12. 対象外

- AIによる文章整形、誤認識の自動補正、CodexやOSコマンドの自動実行。
- ブロック本文の文字単位編集、定型管理の並べ替えUI・全件削除・ピン留め、エクスポート／インポート。定型の選択削除はv0.2.1で実装対象とする。
- 任意の音声認識モデル・パス・コマンド指定、クラウド音声認識、モデル自動ダウンロード、常駐認識デーモン。
