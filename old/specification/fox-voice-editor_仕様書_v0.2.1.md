# fox-voice-editor 仕様書 v0.2.1（実用テスト版）

作成日：2026-10-25  
基準：v0.2.0  
状態：現行仕様。v0.2.0の全規定を引き継ぎ、本書の変更が優先する。

## 1. 変更目的

v0.2.0では、手入力から定型を追加し、並べ替え・追加モードで文書へ複製できたが、不要になった定型を削除する導線がなかった。v0.2.1は履歴の選択・共有メニュー方式を参考に、定型を明示的に削除できるようにする。

## 2. 定型の操作

### 2.1 通常モード

- 「定型」タブでは、定型カードをタップして複数選択できる。選択済みカードの再タップは、そのカードの選択を解除する。
- 選択中の定型を1件以上持つ時だけ、共有操作メニューを表示する。1件では「定型から削除」、複数件では「定型から削除（n件）」と表示する。複数選択時には「選択解除（すべて）」も表示する。
- 削除を実行すると、選択中の定型だけを定型集合から削除し、選択を解除する。
- 定型にピン留め機能、ピン留めUI、全件削除ボタンは設けない。

### 2.2 並べ替え・追加モード

- 文書へのドラッグ複製はv0.2.0どおり維持する。
- このモード中は定型のタップ選択と削除メニューを無効化する。誤ってドラッグ元を削除しない。

## 3. 保存と副作用

- 定型削除は履歴・定型ライブラリの変更であり、Native Hostの正本`~/.local/share/fox-voice-editor/library-v1.json`と拡張側キャッシュへ保存する。
- 削除した定型が履歴にも存在していても、履歴は削除しない。
- 既に文書へ追加したブロックは削除しない。
- Temporary Add-on再読み込み後も、削除済み定型が復元しないことを確認対象とする。

## 4. 実用テスト受け入れ条件への追加

v0.2.0「10. 実用テストの受け入れ条件」に、次を追加する。

10. 定型タブで単一・複数選択、選択解除、選択した定型の削除を確認する。削除後も履歴と既存文書ブロックが残り、再読み込み後も削除済み定型が復元しないことを確認する。
11. 並べ替え・追加モード中は定型をドラッグ複製でき、タップ選択・削除が起きないことを確認する。

## 5. v0.2.0からv0.2.1への変更

- 定型タブに複数選択と共有削除メニューを追加した。
- 定型削除は定型だけに作用し、履歴・文書ブロックを変更しないことを規定した。
- 定型削除を対象外から実用テスト対象へ変更した。定型の並べ替えUI、全件削除、ピン留めは引き続き対象外とする。
